# Planejamento do repositório

## Objetivo

Reunir a apresentação acadêmica e projetos de Matheus Santos com organização, documentação e histórico de versões.

## Organização

- `academicos/`: projetos relacionados à formação e documentação de cada projeto.
- `pessoais/`: projetos independentes, quando desenvolvidos.
- `docs/`: planejamento e registro de versões.
- `assets/`: estilos e futuros recursos visuais da página.
- `index.html`: página publicada pelo GitHub Pages.

O código da página permanece na raiz para simplificar a publicação no Pages. Sua documentação fica em `academicos/portfolio/`.

## Sequência de implementação

1. Revisar os dados pessoais e os textos da página.
2. Enviar os arquivos como versão inicial 1.0.
3. Ativar o GitHub Pages na branch main, pasta raiz.
4. Verificar links, navegação e apresentação em celular.
5. Fazer uma melhoria real e registrar um segundo commit.
6. Adicionar a página e o repositório ao LinkedIn.
7. Gravar a apresentação de aproximadamente cinco minutos.
8. Gerar o PDF final com os links verificados.

## Critérios de revisão

Estrutura clara, README por projeto, histórico de alterações, página pública acessível, integração com LinkedIn e apresentação demonstrando o que foi feito.
