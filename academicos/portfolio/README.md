# PortfolioHUB - projeto inicial

## Contexto e objetivo

Projeto preparado para a entrega intermediária de Bootcamp I. A página apresenta Matheus Santos, estudante do segundo semestre de Análise e Desenvolvimento de Sistemas, e reúne links profissionais e conhecimentos em desenvolvimento.

## Funcionalidades

- Navegação por seções: sobre, tecnologias, projetos e contato.
- Layout responsivo para computador e celular.
- Links para LinkedIn, GitHub e documentação.
- Link para pular a navegação, foco visível e respeito à preferência por movimento reduzido.

## Tecnologias e arquivos

- HTML: estrutura semântica em [`../../index.html`](../../index.html).
- CSS: layout e responsividade em [`../../assets/style.css`](../../assets/style.css).
- Git e GitHub: registro e hospedagem do código.
- GitHub Pages: publicação da página estática, após ativação no repositório.

## Como executar

Baixe ou clone o repositório e abra `index.html`, na raiz, em um navegador. Nenhum pacote precisa ser instalado.

## Verificação manual

1. Abrir a página em computador e celular.
2. Navegar com os links do cabeçalho.
3. Conferir os destinos de LinkedIn, GitHub e documentação.
4. Navegar com a tecla Tab e conferir o foco visível.
5. Depois da publicação, abrir o endereço do Pages sem estar autenticado.

## Versionamento e evolução

A versão inicial é `1.0`. Após o primeiro commit e a publicação, registrar uma melhoria real em um segundo commit, como adicionar uma seção de objetivos de aprendizado. Não registrar como concluída uma mudança que ainda não foi enviada.

## Limitações

Não há backend, formulário ou banco de dados. Os conhecimentos citados não representam certificações nem níveis de proficiência. Projetos pessoais ainda não foram adicionados.
